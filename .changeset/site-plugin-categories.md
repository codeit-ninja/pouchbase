Browse plugins on pouchbase.io and filter them by category. The plugin manifest's JSON Schema is served at `/schemas/plugin-manifest.json`, and the plugin docs cover the server helpers for sign-in providers, the `init` templates, `add`, dev versions, provider icons and the `@pouchbasejs/ui` components plugins can use. They also explain where plugin server code runs and how `permissions.network` wildcards match, and the authentication docs cover sign-in providers from plugins and their logos.
